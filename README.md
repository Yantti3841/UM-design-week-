# 桃花源 · UMDW 2026 Identity Generator

按 1014 最终 AI 的标注，选择背景、个人身份和配色，生成一朵逐层叠加的桃花。

## 本地使用

```sh
pnpm install
pnpm dev
pnpm build
```

本项目使用 React + Vite、Cloudflare Worker、D1 数据库和 WebSocket。完成后的花朵、身份参数及原始 SVG 保存到云端；制作中的未提交设置刷新会恢复默认。旧版浅灰前端仍保留在 `/frontend-v15/`。

## 现场使用

- 双击 `打开桃花程序.cmd`，自动启动本机程序，并在默认浏览器打开制作页和花海页。地址为 `http://127.0.0.1:4180/` 与 `http://127.0.0.1:4180/wall`。
- `/`：浅灰版制作页。完成七步后点击大按钮「让桃花上屏」，所有打开 `/wall` 的大屏会同步出现该花朵；参与者无需登录，可分别使用自己的手机。只有数据库确认保存后才显示成功，失败重试沿用同一个提交编号，避免重复。
- `/wall`：唯一花海页。花朵保持方向持续游走，只有花朵互相接触或触及屏幕真实四边时反弹。已移除标题、二维码的隐形碰撞区与空中转向力。不再提供示例切换、工具栏、计数或演示说明。最多同时显示最近 60 朵，全部作品继续保留。
- 投影底板恢复 OutdoorWall 原 AI 的曲线、细环、PEACH / BLOSSOM / SPRING、桃花源与日期的原始坐标。绘制顺序为后方曲线与细环 → 原生轮廓文字 → 前景渐变色带 → 参与者桃花；移除原稿中固定的示例花和赞助标识。两组原生软遮罩以 3840 像素透明 PNG 提取，保留原渐变与高光；文字仍为原生矢量。按用户最新参考等比放大，轻裁左侧、顶部和右侧出血，裁剪贴合屏幕边缘，主要文字保持完整。
- 主视觉按可见内容的高度垂直居中，在正常电脑比例下整体下移，字号、横向裁剪与原始叠层保持一致。
- 花朵再缩小 12%，以 120 Hz 固定步长计算物理，每个显示帧插值位置。碰撞时保留切向速度，法向以 0.9 恢复系数反射，碰撞后的漂浮速度用 6 秒时间常数逐渐恢复，不改变飞行方向。花朵之间用圆形碰撞体积；屏幕边界按每朵 SVG 的可见像素范围判定，忽略透明留边。靠近底边的署名改放在花朵上方，不再为署名额外抬高下边界。
- 大屏游走独立于花内的静止／旋转设置。系统减少动态效果时以较慢速度游走；不再因该设置或嵌入浏览器的隐藏标记完全停止。切回页面时限制时间增量，避免突然跳跃。
- `/archive`：查看所有已收集的云端作品，单独下载 SVG，或打包下载所有原始 SVG 与完整配置 JSON。大屏只取最近 60 朵，作品库和导出没有这个限制。姓名为参与者自愿填写的公开署名。
- `/frontend-v15/`：新增投影功能前的独立旧版前端。

1. 投影电脑联网，浏览器打开投影页，按 F 全屏，系统设置关闭自动休眠。
2. 手机扫描大屏右下方二维码，完成七步后点击「让桃花上屏」。手机可以使用自己的移动网络，不要求与电脑处于同一 Wi-Fi。
3. 大屏通常在 1–2 秒内显示新作品。断网期间已有花继续运动；恢复网络后自动重连并补齐。网络不支持 WebSocket 时自动使用 HTTP 同步，作品仍可上屏。
4. 活动结束后从作品库点击「导出全部作品 ZIP」，保存 SVG 和配置备份。云端作品不会因关闭浏览器或刷新而丢失。

本机启动器直接打开正式公网制作页和投影页，二维码也指向正式公网制作页，两端使用同一份共享作品库；原有本机 4180 入口会自动转到正式网址。`pnpm dev` 则使用隔离的本地 D1 测试数据库，不会写入现场作品。

## 视觉与控制

- `public/assets/pattern-01.svg` 至 `pattern-21.svg` 直接提取自用户提供的 `UMDW-PeachBlossom-DataPatterns.ai` 的 PDF 兼容内容，保留原始路径。
- 保留主视觉灰底与限定色，移除海报预览及底部生成流程。旧海报素材仍保留在素材目录中。
- 新素材位于 `public/assets/final1014/`，40 个原始画板共同使用 700 × 700 坐标，不分别放大。
- 姓名为可选公开署名，也用于下载文件名；六组语义映射为领域、学术/业界、设计周身份、从业年限、地区与跨学科。
- 专精／跨学科对应圆形／四圆背景；学术／业界对应小／大点环，选项放在地区下面。中国范围包括内地及港澳台，蓝色地区图案对应大洋洲。
- 配色提供六组原始三色方案，以小色点显示，仅调整背景颜色并保留身份图案。
- 从业年限和学术／业界联系各提供一个 0–100 滑杆：资历越高，绿色尖刺越短；越靠近业界，18 个浅色点越向外散开。原图形按钮与滑杆同步，返回保留中间值，导出包含连续形态。新人／中级／资深以及学术／业界端点保留原始矢量。
- 全局动效提供静止、旋转、呼吸及一个速度滑钮。一个 requestAnimationFrame 循环直接更新 SVG 变换，不在每帧触发 React 渲染。
- 动效使用慢速分层旋转和错相呼吸；调速不重置动画角度，静止恢复原始构图。
- 完成制作后可从折叠示例选择器查看八个原始示例，并返回步骤修改。
- 首次打开仅显示原始粉色桃花底图。七步依次选择领域、专精／跨学科、年限、身份、地区、学术／业界联系和配色。每步只有当前一组选项，点击后对应图层渐显，再点击下一步；上一步保留其他配置，重新开始保留桃花底图，清空个人选择。
- 手机采用固定一屏的上方花朵、下方选择布局，正常高度约为四比六。使用 visualViewport 实际高度和偏移响应浏览器／微信顶部栏，短屏自动收紧间距与预览比例；页面、选项均不需要上下滑动，保留安全区域。输入名字时若键盘压缩可视区域，暂时收起预览以保留表单与导航。
- 花朵上方不显示制作进度或提示条。花朵始终等比缩放并放大显示；移除花朵下方的标题、身份文字和选择提示，标题改为「制作属于你自己的桃花」。绿色年限图形选项略微放大。浅色点环选项使用深色底提高对比，步骤与图形依次缓动出现；系统减少动效时关闭渐显。
- PNG / SVG 导出当前运动帧，尺寸 1200 × 1200，保留透明背景与原始矢量路径。导出为静态图案。
- 系统启用减少动态效果时，默认静止；主动选择旋转或呼吸即可播放。
- 中文 / EN 切换包括所有控制、图案名、身份信息、下载菜单和状态提示，切换语言不改变花朵配置。

## 源码

- `src/generator.js`：限定色、身份映射、种子与 SVG 素材处理。
- `src/Flower.jsx`：按已选择参数叠放原始图案、图层渐显与四个细节层的动效循环。
- `src/Controls.jsx`：七步选择、上一步／下一步、完成页与八个原始示例。
- `src/main.jsx`：大花实时预览、逐层生成、语言切换和导出。
- `src/i18n.js`：中英文界面文本。
- `extract-assets.py`：读取原始 AI 兼容内容并提取素材；需要 PyMuPDF，运行时不需要 Python。
- `extract-final-assets.py`：提取 1014 最终图案，以及分离地区色盘、中心点阵与示例底图变体。
- `FINAL-1014-review.md`：原始文字含义、叠层顺序、示例差异与审阅结果。

视觉参考优先级：用户本次要求、两份 UMDW 原始 AI、新 handoff 文档、旧界面截图。采用更窄的面板，替代 handoff 中旧的 40% 宽度。

## 管理平台

- `/admin`：使用已授权的 ChatGPT 账号登录。匿名访问与未授权账号均不能查看管理数据或执行管理操作；手机制作页和大屏继续公开访问。
- 后台提供署名／编号搜索、状态筛选、分页查看、撤下、重新上屏、回收站及恢复。撤下仅影响大屏，公开作品库继续保留；回收站作品从大屏、公开作品库和公开导出中隐藏。
- 输入署名或编号后自动在全部作品中搜索，避免沿用回收站等状态筛选而找不到新作品。搜索结果仍可按状态缩小范围，并显示当前搜索范围。
- 回收站不永久删除原始 SVG 或配置；恢复时回到删除前的上屏／撤下状态，避免把原本不展示的作品自动放回大屏。
- 后台「导出全部作品」包括回收站，公开作品库的导出不包括回收站。
- 网站部署后的首次使用，请刷新一次已经打开的大屏，使其加载支持管理同步的新版客户端。之后管理操作会通过 WebSocket 自动同步；受限网络的 HTTP 后备同步也会移除已撤下的花。
- 管理员账号由 Sites 的运行时私密变量 `ADMIN_EMAIL` 指定。账号身份由 Sites 原生 ChatGPT 登录验证，不在前端保存管理密码，也不根据浏览器传来的角色字段授权。更换授权账号需要更新该变量并重新部署。
- 本地测试可以设置 `UMDW_ADMIN_EMAIL` 后启动隔离数据库；本地身份头只供自动化测试使用，不代表已经验证真实账号登录。正式环境通过托管平台验证并注入登录身份。
- 数据库迁移给现有作品增加默认上屏状态，不删除历史记录。管理状态和同步版本在数据库事务中一并更新；多窗口修改旧状态时返回冲突并刷新，避免覆盖新操作。

## 后端与运行

- `server/api.js`：校验与幂等提交、分页读取、WebSocket 增量同步、原始 SVG 与流式 ZIP 导出。
- `server/flower.js`：只接受合法生成器参数；和前端共用 `src/flowerSvg.js`，保持原稿图层顺序。
- `db/schema.js` / `drizzle/`：D1 schema 与已生成迁移；正式部署由 Sites 应用迁移，不在请求中创建表。
- `src/collection.js`：上传、WebSocket 心跳与重连、HTTP 后备同步。每个大屏通过游标读取共享数据库，不依赖某台 Worker 的内存，因此不同电脑和服务实例都能接到作品。同步间隔 1.5 秒。
- `scripts/build.mjs`：构建客户端与自包含 Worker；保留 Sites 构建集成及迁移。
- `pnpm dev`：本地隔离数据库，制作页 `http://127.0.0.1:5173/`。
- `pnpm build && pnpm preview`：本机 4180 入口自动转到正式公网页面，供投影使用。
- 测试构建可设置 `UMDW_LOCAL_DATABASE=1`、`UMDW_PORT=4182` 后运行 `node scripts/preview.mjs`，使用隔离的本地持久数据库。测试数据不自动导入云端。

活动依赖手机和大屏都能访问正式网址；页面会保留已有花朵并自动重连，但断网时无法上传。当前没有收费配置或外部数据库账号，托管平台的实际用量及限额以账户为准。活动前仍需在现场网络与投影设备上扫码试用。
